TRAINING-FREE · CSJ · JAPANESE ASR

A voice agent that remembers rare words across sessions

The agent finds rare words in its own transcripts without labels, writes them to memory only when a kana CTC model hears them too, and offers them back to the decoder in later talks after the same acoustic check.

  1. DetectRare units in each hypothesis: UniDic nouns, compounds merged, outside the 5,000 most frequent units of CSJ train.
  2. WriteKept only when the CTC agrees: reading support ≥ 0.85, CTC confidence ≥ 0.6, heard in at least 2 utterances of the talk.
  3. RecallIn later talks an entry reaches the decoder only if its reading is found in the CTC kana (fuzzy ratio ≥ 0.8), top 30 by score.

照合Acoustic check

Fuzzy matching without word boundaries

Kana CTC output has no word boundaries, so a reading is compared with every window of length n−1 to n+1 in the CTC string. The score is Levenshtein.ratio, one minus the indel distance over the total length. The best window decides: at 0.80 or above, the memory entry is offered to the decoder.

Metric definitions

CER
Character error rate on normalised text (NFKC, no spaces or punctuation).
B-CER
Errors on reference characters inside rare-word spans. An insertion counts here only when both neighbouring characters are rare.
U-CER
Errors on all other characters.
term_R / term_P
Recall over rare-word occurrences in the reference; precision over rare words plus offered hotwords.
harmful
Share of characters B0 got right that this system gets wrong.
induced_fp_per_1k
Offered hotwords that appear more often than in the reference, per 1,000 reference characters.
mem_poison
Injected wrong entries still alive in memory (poison experiment).

手順Pipeline

From a CSJ data directory to this page

Set C=configs/base.yaml. Every step reads the config; ./run_toy.sh runs the same chain on a synthetic corpus with mock backends in about ten seconds.

  1. Manifests

    Kaldi/ESPnet data dirs (wav.scp, segments, text) to JSONL. Use only talks the models never trained on as sessions.

    python scripts/prepare_csj.py --data-dir $ESPNET/egs2/csj/asr1/data/eval1 --out work/csj/manifests/eval1.jsonl→ work/csj/manifests/*.jsonl

  2. Rare-word definition

    Count content units on CSJ train; anything outside the top N is rare.

    python scripts/build_rare_vocab.py --config $C→ work/csj/rare/vocab.tsv, common_top5000.txt

  3. Session sequences

    Group talks by domain (or speaker), with a random grouping as the control, and draw permutations.

    python scripts/build_sequences.py --config $C --group-by domain --out work/csj/seq_domain.json→ work/csj/seq_domain.json, seq_random.json

  4. Go / no-go

    Rare-word recurrence between talks, from references only. If it is low, memory cannot help.

    python scripts/go_nogo.py --config $C --sequences work/csj/seq_domain.json work/csj/seq_random.json --out work/csj/go_nogo.csv→ work/csj/go_nogo.csv

  5. Run systems

    Resumable. CTC and decoder outputs are cached per utterance and hotword set, so systems share work.

    python scripts/run_longitudinal.py --config $C --exp main --sequences work/csj/seq_domain.json --n-perm 5 --systems B0 B1 B2 B3 B4 B5 P→ runs/main/<system>/<seq>/perm<k>/

  6. Evaluate

    Overall table, per-talk curves, memory quality and the paired bootstrap.

    python scripts/evaluate.py --config $C --exp main --baseline B0 --compare P→ runs/main/eval/*.csv

  7. Sweep and poison

    Exp1 precision–recall sweep over logged candidates; Exp2 injects wrong entries before the first talk.

    python scripts/sweep_write_gate.py --config $C --exp main --system P-noRepeat python scripts/make_poison.py --config $C --sequences work/csj/seq_domain.json --k 5 --out work/csj/poison.json→ runs/main/eval/write_gate_sweep_P-noRepeat.csv, runs/poison/

  8. Export to this page

    Collects the tables, a replay trace and the code map into one data file next to this page.

    python scripts/export_site_data.py --config $C --exps main poison --out site/data/results.js→ site/data/results.js
